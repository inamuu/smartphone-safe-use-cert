# スマホ安全活用検定

中学生向けに、親子で取り組むスマートフォン安全利用教材です。全24章を順次公開します。公開中の章はホームと `published.json` で確認できます。

## 学び方

各章は、専用の挿し絵・説明・理由・具体例・行動例・考える問いのある8項目と、途中の判断練習3問で構成します。1章15〜25分を目安に、休みながら学べます。

学習後は16問の問題バンクから、重要問題を必ず含む10問をランダムに出題します。問題と選択肢の順番を変え、90点以上かつ重要問題への正答で章ごとに合格します。解説から対応する学習画面へ戻り、何度でも受け直せます。

各章の合格は、全課程の修了やスマホの利用許可ではありません。保護者認証や端末の使用制限機能はありません。点数に加え、理由を自分の言葉で説明できるか、家族と話し合ってください。

## 開発・公開

Python 3とNode.js 22以上を使います。追加パッケージは不要です。

```sh
python3 build.py
node test.mjs
python3 -m http.server 8080
```

`http://localhost:8080/` から章を選びます。例：`http://localhost:8080/?chapter=3#/learn`。

GitHub Pagesは `main` のルートを公開します。`index.html` と `assets/lessons/` を一緒に配置してください。

公開URL：https://inamuu.github.io/smartphone-safe-use-cert/

## 編集するファイル

| ファイル | 内容 |
| --- | --- |
| `index.template.html` | 共通画面・スタイル・学習と受験の動作・第1章問題バンク |
| `lessons.json` | 第1章の本文・判断練習・画像説明 |
| `chapterN.json` | 第2章以降の本文・判断練習・問題バンク。第3章以降は章別の一次資料も記載 |
| `published.json` | 公開する章番号。1から連続して指定 |
| `assets/lessons/*.jpg` | 教材用に生成したイラスト |
| `build.py` | 公開する教材・画像・設問の構造を検証し、データをHTMLへ埋め込む |
| `index.html` | 生成済みの公開エントリーポイント |
| `test.mjs` | 全公開章の出題・合否・学習導線・保存を検証 |

第3章以降の画像は、1章分の専用イラスト8場面を2列×4行の画像にまとめています。各項目の `imagePanel`（0〜7）に対応する場面だけをCSSで表示します。本文とは別の機器設定図や、実際に入力する画面ではありません。画像内に秘密の文字列や有効なQRコードは使用しません。

章を追加する場合は、8項目・判断練習3問・16問（重要問題1問）のJSONと画像を用意し、`published.json` を更新してからビルド・テストします。未公開章のJSONは自動的には公開画面へ入りません。出典を確認し、本文と正解・解説の対応もレビューしてください。

## 学習記録とプライバシー

第1章の保存キー `smartphone-safe-use-cert:v1` は維持します。第2章以降は `smartphone-safe-use-cert:chapterN:v1` に独立保存し、以前の記録を引き継ぎます。家族の約束は `smartphone-safe-use-cert:family:v1` で共有し、初回は第1章の既存下書きから読み込みます。章のリセットでは他章や家族ルールを消しません。

名前・メールアドレス・本物のパスワードは入力させません。学習進度・各章直近20回の結果・家族ルール下書きはブラウザ内だけに保存します。本サイトのコードからの学習記録送信、端末間同期、広告、解析、外部フォントはありません。GitHub Pagesでは通信に伴う情報が処理されます。ブラウザの保存データは改変可能なため、正式な本人認証付き試験ではありません。

## 内容の方針

具体的な場面で判断する力を育て、失敗したあとでも相談できる構成にします。被害を受けた人や相談したこと自体を責めず、まず安全を守ります。サービスや端末によって異なる設定・保存・復元の動作を一律に断定しません。法律の紹介は行動の理解を助けるための基礎とし、個別事案の法的判断は行いません。

参考にした一次資料は「保護者の方へ」に章別に記載します。家庭ルールの例と合格基準は本プロジェクト独自の提案です。教材用のイラストは生成AIで作った架空の人物です。
