# スマホ安全活用検定

中学生向けの、親子で取り組むスマートフォン安全利用教材です。

**第1章「スマホを持つ目的と責任」・第2章「インターネットの仕組み」を公開中**です。全24章のうち、残り22章は準備中です。

## 現在の機能

- 各章8画面。各項目に説明・具体例・行動例と専用イラスト、各章3問の判断練習
- 全16項目それぞれの専用イラスト、写真共有・相談の会話例、家族で考える問い
- 学習時間の目安15〜25分。途中で休み、何度でも読み直せます
- 各章16問から重要問題を含む10問をランダム出題、選択肢も並べ替え
- 90点以上、かつ「助けを求める」重要問題への正答で各章合格
- 全問解説、対応する学習画面への移動、回数制限なしの再受験
- 学習進度・直近20回の結果・家庭ルール下書きをブラウザ内に保存
- スマートフォン対応、キーボード操作、外部フォント・解析・広告なし

各章の合格は、全課程の修了やスマホの利用許可ではありません。保護者認証や端末の使用制限機能はありません。

## ファイル

- `index.template.html`: スタイルとアプリの編集用ソース
- `chapter2.json`: 第2章の8項目と16問の問題バンク
- `lessons.json`: 教材の本文、具体例、会話例、行動例、画像説明
- `assets/lessons/*.jpg`: 各項目専用の16枚のイラスト
- ホームの既存画像は `index.html` 内に埋め込み、学習用の挿し絵は `assets/lessons/` を参照します。
- `build.py`: 教材データを埋め込み、全16枚の画像の存在も検証して `index.html` を生成
- `index.html`: GitHub Pagesの公開エントリーポイント
- `test.mjs`: 出題、正解の対応、合否境界、重要問題、保存データ検証

## 開発・確認

Python 3とNode.js 22以上を使用します。追加パッケージは不要です。

```sh
python3 build.py
node test.mjs
python3 -m http.server 8080
```

`http://localhost:8080/` を開きます。公開時は `index.html` と `assets/lessons/` を一緒に配置してください。
